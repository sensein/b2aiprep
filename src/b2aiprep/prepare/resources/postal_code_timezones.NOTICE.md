# postal_code_timezones.csv, region_timezones.csv and postal_code_regions.csv

Generated by `scripts/build_postal_code_timezones.py`. Do not edit by hand.

Used by `b2aiprep.prepare.date_shift` to localize self-administered sessions in the time zone the
participant reported living in. Each postal code's zone is assigned by point-in-polygon on its
centroid with `timezonefinder`. `region_timezones.csv` lists only states and provinces whose
every postal code falls in one zone.

## Sources

- **US ZIP codes:** [zip2info](https://github.com/Three-Ships/zip2info) at commit `5876e295eb`
  (MIT License). Its coordinates come from U.S. Census ZCTA gazetteer centroids (public domain)
  and GeoNames postal codes (CC BY 4.0).
- **Canadian forward sortation areas and US ZIP → state:** [GeoNames](https://www.geonames.org)
  postal code dumps `CA.zip` and `US.zip`, licensed under
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
